# Echoes of BIC

A realistic horror job simulator. You work the front desk of a university's international student help desk: check each visitor's ID and paperwork against the rulebook, then approve, reject, or call security.

Most people are exactly who they say they are.

**[Play in the browser](https://zahiddiff.github.io/echos-of-bic/)** — always the latest build from `main`.

Early build: gray-box art and placeholder sound.

## Controls

| Key | Action |
|---|---|
| WASD | Move |
| Mouse | Look |
| E | Interact / work the desk |
| Mouse (at the desk) | Drag papers and the magnifier; click the stamp, rejection slip, radio or terminal |
| Esc | Step back / release the mouse |

## Running locally

Open `project.godot` in Godot 4.7 and press F5.

Tests: `tools/run_tests.sh path/to/godot`

Made with Godot 4.7 and GDScript.
